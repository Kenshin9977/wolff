# scriptbundle / objectivedata's 0x20a0070 (0x20, profile hand_shapes): its loop over the pointer
# array at 8 is rotated by clang (`sub r12, 1; jb out` mid-loop, then the loop-invariant type test

# through DB_RewindPrepare (mode 0, 0x20a00df): when the type u8@0 is 6, each non-null element
# through DB_RewindPrepare (0x20a017f) to a 0x20 struct read by 0x209f9e0 (0x20a01b5); else the
# array alone. Then u32@0x1c elements of 0x18 at 0x10 (0x20a021b), 0x209f870 run on each in place.
# The skip-0 test of stream.rewind_prepare.lookup on each answer, as the generated tables have it.
### f20a0070

SUM|rwa|u8|0|0
IF|(u64@0x8 >> 63) != 0

READ|8
SUM|rwa|u64|$da|1
ENDIF
IF|((((u64@0x8 & 0x9000000000000000) != 0) & ((((u64@0x8 >> 63) == 0) + ((($rwa >> 24) & 0xffffff) != 0)) != 0)) & 0xff) == 1
IF|u8@0x0 == 6
ARRAY|u32@0x18|0x8|f20a0070_e1
ELSE
READ|(u32@0x18 * 8)
ENDIF
ENDIF
ENDIF
IF|u64@0x10 != 0
SUM|rwb|u8|0|0
IF|(u64@0x10 >> 63) != 0

ENDIF
