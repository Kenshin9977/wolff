# scriptbundle / objectivedata's 0x21d2d00 (0x20, profile hand_shapes): its loop over the pointer
# array at 8 is rotated by clang (`sub r12, 1; jb out` mid-loop, then the loop-invariant type test

# through DB_RewindPrepare (mode 0, 0x21d2d6f): when the type u8@0 is 6, each non-null element
# through DB_RewindPrepare (0x21d2e0f) to a 0x20 struct read by 0x21d2670 (0x21d2e45); else the
# array alone. Then u32@0x1c elements of 0x18 at 0x10 (0x21d2eab), 0x21d2500 run on each in place.
# The skip-0 test of stream.rewind_prepare.lookup on each answer, as the generated tables have it.

ENDIF

IF|u8@0x0 == 6

ELSE

ENDIF
ENDIF
ENDIF
